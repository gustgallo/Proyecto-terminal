# LEGACY: despliegue Node anterior

Esta carpeta se conserva únicamente como referencia histórica de la arquitectura Node/Cloud Run anterior.

No corresponde a la versión 3.0 de producción. La versión actual usa:

```text
React + API PHP en GoogieHost -> MariaDB local mediante localhost/socket
```

`cloud-run-env.yaml` contiene solo marcadores y no credenciales reales.

Para la instalación vigente consulta el `README.md` de la raíz y `deploy/googiehost/README.md`.
